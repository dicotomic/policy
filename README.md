# DELEGADO · Sitio de políticas

Sitio estático listo para publicar en GitHub Pages.

## Archivos incluidos

- `index.html`: página principal.
- `privacy.html`: política de privacidad.
- `security.html`: política de seguridad de la información.
- `terms.html`: términos y condiciones.
- `data-deletion.html`: instrucciones para eliminación de datos.
- `styles.css`: estilos visuales.

## Antes de publicar

Reemplaza estos datos en todos los archivos:

- `contacto@tudominio.com`
- `[Nombre legal o razón social]`
- `[Dirección o ciudad, país]`
- `DELEGADO`, si usarás otro nombre comercial.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo: `delegado-politicas`.
2. Sube todos estos archivos a la raíz del repositorio.
3. En GitHub, entra a `Settings` → `Pages`.
4. En `Build and deployment`, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda los cambios.
6. GitHub entregará una URL pública similar a:
   `https://tuusuario.github.io/delegado-politicas/`
